CASE STUDY / 03

MAGIC FACTORS / 丽典

护肤品视觉设计

护肤品系列视觉产品海报 · 电商详情设计

01 / COMMUNICATION

传播任务

海报集中呈现产品、主题与品牌识别，让单个产品先被看见；详情页则把产品展示、成分信息与使用感受分段展开。

这个案例选取同品牌的海报与详情页作品，拆解两种载体的信息层级与视觉表达。

作品范围
产品海报 / 电商详情页
展示重点
产品主视觉 / 系列识别 / 长图编排
02 / VISUAL LANGUAGE

系列识别

两张海报都保留品牌标识、上方主题和下方产品主体。精华液以粉色、织物与柔和高光呈现；精华油则使用黄绿对比、油滴与植物元素。

统一的是阅读次序；变化的是背景色彩与辅助元素。产品始终占据画面的主要位置。

03 / READING FLOW

阅读顺序

面霜详情页从产品主视觉开始，依次展开成分、质地、人物与使用场景，最后回到产品。浅色背景贯穿页面，棕金色标题标记每段重点。

  1. 产品亮相先建立产品与主题印象
  2. 信息展开用独立段落承接成分与质地内容
  3. 场景切换人物画面调节长图阅读节奏
  4. 产品收尾回到包装与品牌识别

05 / SALES COLLATERAL

销售物料

08 / PROJECT OUTCOMES

持续延展的设计体系

这个项目体现的不是一次性风格创作，而是在既有品牌体系中持续解决真实需求：先明确规则，再完成高频物料，并保留足够弹性适配不同规格、语言与渠道。

统一：包装与宣传物料使用更稳定的信息层级延展：同一品牌语言覆盖包装、海报、折页与手册适配：支持多规格、多语言与不同销售场景
